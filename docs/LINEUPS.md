# One event, six competing teams

`npm start` launches the six-team event with actual configured input. There is no built-in fake roster. `npm run demo` is a compatibility alias for this same launcher, not a second app. Automated tests keep their fictional fixtures separate.

The default encrypted path is `.rival-reaper/session-six-v1.enc.json`; it does not load old disposable demo saves. Existing files are not erased automatically. Require the configured private roster, token and encryption key. Keep them outside public Git.

Internal `five-v1` compatibility remains for explicit recovery/testing only. It is not a second product or the normal launch. Saved-state mismatch checks still prevent silently reinterpreting existing fates. The launcher rejects mismatched saved data rather than resetting it.

All capacities and balancing quotas derive from validated input. Never invent a participant to make an even division. Support is excluded from the competitive draw.
