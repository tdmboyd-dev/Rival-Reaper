# Current Game Concepts

Status in this file is intentionally strict.

- **CONCEPT LOCKED** = owner accepted the concept/direction.
- **PARTIAL RULES** = enough exists to continue, but not production-ready.
- **OPEN** = exact mechanics still need owner approval.
- **FINAL** = only use this when the owner explicitly approves the complete game card.

---

## 1. Fuck Around Die

**Status:** CONCEPT LOCKED / PARTIAL RULES

### What it is
A reusable **game mutator**, not necessarily one standalone game.

A normal game can already be underway. Blackout rolls the die and the approved result changes the game.

Examples discussed:
- anchor moves;
- one player changes hands;
- somebody stands on one foot;
- team loses a player;
- player added;
- positions rotate;
- player freezes;
- opponent gets an advantage;
- sudden rule change.

### Why it exists
It prevents predictable physical games from always being won by the obvious strongest lineup and lets the same equipment feel different each year.

### Blackout role
Blackout controls:
- when the die is rolled;
- what result is active;
- when it starts/ends;
- whether a result is unsafe or impossible and must be rerolled.

### Equipment
- Giant die / giant foam die — discussed as a needed/planned purchase.

### Still open
- exact number of die faces/results;
- full approved result table;
- whether different games use different die tables;
- frequency of rolls;
- scoring effect.

## 2. Protect Yo' Problem

**Status:** CONCEPT LOCKED / PARTIAL RULES

### Base
Twisted dodgeball.

### Core idea
Each team has a protected/secret “problem” player. The game is not just about eliminating everybody. Teams must protect their own problem while identifying and attacking the opponent's.

### Existing equipment
- **11 six-inch dodgeballs** are confirmed already owned.

### Intended energy
People should be yelling, bluffing, shielding, switching positions and trying to figure out who actually matters.

### Still open
- how the protected player is selected;
- whether the identity is secret from the other team;
- whether hitting that player ends the round instantly or triggers another consequence;
- normal elimination rules;
- headshot/out-of-bounds rules;
- player count;
- scoring.

Do not mark these mechanics final until owner approves.
