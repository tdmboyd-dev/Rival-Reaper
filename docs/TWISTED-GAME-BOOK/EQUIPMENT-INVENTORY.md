## Important purchasing rule

Do **not** buy an item just because it appears in a brainstorm.

Purchase flow is:
1. game concept;
2. executable rule card;
3. owner final approval;
4. inventory comparison;
5. exact quantities/specifications;
6. purchase list.

This inventory is therefore a planning baseline, not a final shopping cart.

## Equipment check required on every approved game

Every final game must include:

### Already Have
List the exact inventory items it uses.

### Need to Buy
List only the missing items required to run the approved version.

### Optional / Upgrade
Anything that improves presentation but is not required to run the game.

### Quantity / specification
Do not write “cups” or “balls” if the game needs a specific amount/size. After approval, convert vague items into exact purchase quantities.
