# Rival Day Twisted Game Book

This folder is the recovered working source of truth for the **Family & Friends Rival Day Twisted Game Book**.

It is not a generic school-field-day manual. The intended voice is urban, plain-English, Rated-R when appropriate, funny, trash-talk-heavy, and easy enough that somebody can pick up a game card and run it without guessing.

The core personality is:

> **Field Day is organized chaos with a whistle around its neck.**

The games should feel like a family cookout collided with a fantasy sports league and a hood Olympics. The writing can talk shit, but the actual instructions must stay crystal clear.

## What is already established

- Blackout Krew runs/referees the circus.
- The book should target roughly **15–20 reusable core games** plus secret household wildcard games.
- Existing named concepts include:
  - **Fuck Around Die** — reusable rule mutator.
  - **Protect Yo' Problem** — twisted dodgeball/protected-player concept.
  - **Granny Ain't Shit Relay** — oversized-granny-pants relay.
  - **Betrayal Rope** — twisted tug-of-war.
  - **Bounce or Bullshit** — bounce/cup/accuracy pressure game.
- Existing normal equipment should be reused wherever possible instead of buying custom carnival gear.
- Every finished game needs a complete executable card.
- Nothing becomes final merely because AI proposed it. Owner approval is required.
- After approval, equipment is split into:
  - **Already Have**
  - **Need to Buy**
  - **Optional / Upgrade**
- The purchase list only comes from approved game requirements.

## Folder map

- `OPERATING-RULES.md` — tone, referee rules, fairness, safety, scoring boundaries.
- `EQUIPMENT-INVENTORY.md` — confirmed already-owned gear and known missing/planned supplies.
- `CURRENT-GAME-CONCEPTS.md` — recovered game concepts and what is/is not finalized.
- `GAME-CARD-TEMPLATE.md` — mandatory format for every proposed/final game.
- `APPROVAL-AND-PURCHASE-WORKFLOW.md` — how AI and owner move a game from idea to playable.
- `PURCHASE-LEDGER.md` — current known shopping/reminder list and status rules.
- `AI-HANDOFF.md` — instructions for another AI continuing the book.

## Source-of-truth rule

Do not invent missing rules and mark them approved. If a detail was not locked, mark it **OPEN / NEEDS OWNER APPROVAL**.

The newest explicit owner correction always beats older notes.
