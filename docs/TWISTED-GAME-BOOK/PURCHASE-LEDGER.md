## How to update this ledger

When a game is owner-approved:

1. list all required equipment;
2. subtract confirmed inventory;
3. combine duplicate purchase needs across games;
4. calculate exact quantity;
5. mark requirement source by game;
6. owner approves purchase;
7. after purchase, move item into owned inventory with quantity/date if known.

## Status vocabulary

- **HAVE** — owner already has it.
- **NEED / PLANNED** — discussed as needed, not confirmed purchased.
- **APPROVED TO BUY** — owner explicitly approved purchase.
- **PURCHASED** — confirmed obtained.
- **OPTIONAL** — not required to run approved game.
