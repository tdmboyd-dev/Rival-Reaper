# Mandatory Game Card Template

Every proposed or final Rival Day game should use this structure.

---

# [GAME NAME]

**Status:** IDEA / DRAFT / OWNER-APPROVED / FINAL  
**Version:**  
**Owner approval date:**  

## What the hell is this?

One short paragraph in Rival Day voice explaining the game.

It should be funny enough to have personality and simple enough that a player understands the point immediately.

## Players

- Players per team:
- Number of teams at once:
- Adult/kid restrictions if any:
- Substitution rule:

## Objective

One or two sentences.

Example format:
> Get your whole squad through the course before the other team without getting your secret player smoked.

## Equipment

### Already Have
- item
- quantity/specification

### Need to Buy
- item
- exact quantity/specification

### Optional / Upgrade
- item
- why it helps

## Setup

Numbered, literal setup instructions.

1. Put X here.
2. Mark the line.
3. Set Y feet between the cones.
4. Blackout checks the field.
5. Players report to start position.

No vague wording.

## How to play

Numbered steps.

A person who never saw the brainstorm should be able to run the game from this section.

## The fucked-up part / twist

Explain what makes this a Rival Day game instead of a school Field Day game.

If Fuck Around Die applies, specify:
- when it can be rolled;
- which result table applies;
- how long the mutation lasts.

## How you win

State one objective win condition.

Do not use “best performance” unless it is defined.

## Scoring

Until a universal point table is owner-approved, state:
- round winner;
- placement;
- points proposal;
- whether the proposal is OPEN or APPROVED.

## Fouls / bullshit that does not count

List:
- line violations;
- illegal contact;
- skipped obstacles;
- early starts;
- equipment misuse;
- whatever is game-specific.

## Blackout/referee instructions

What Blackout must watch:
- start;
- boundaries;
- score;
- twists;
- reset;
- arguments;
- tie conditions.

## Safety

Direct safety rules only.

## Tie-break

Exact tie procedure, or mark OPEN if not yet approved.
